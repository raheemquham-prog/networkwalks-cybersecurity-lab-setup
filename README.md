# 🔐 Cybersecurity Lab Setup | NetWalkWorks Internship

## Overview

This repository documents my hands-on cybersecurity lab setup and practical exercises undertaken during my internship at **NetWalkWorks**.

The objective of this lab is to build practical cybersecurity skills through virtualized environments, network configuration, vulnerability assessment, and penetration testing exercises.

Rather than focusing solely on theoretical concepts, this project provides a practical environment for understanding how systems and networks operate, identifying security weaknesses, and exploring techniques used to assess and improve system security.

## 🎯 Lab Objectives

* Understand network architecture and communication.
* Configure virtual machines and isolated lab environments.
* Develop practical Linux administration skills.
* Understand common network vulnerabilities.
* Perform vulnerability assessment and basic penetration testing.
* Explore web application security.
* Practice identifying and documenting security misconfigurations.

## 🧪 Lab Environments

The lab incorporates intentionally vulnerable systems and applications for authorized security testing and practical learning.

### 1. Network Security

* Network discovery and enumeration.
* Port scanning and service identification.
* Understanding network communication.

### 2. Vulnerability Assessment

* Identifying common system vulnerabilities.
* Understanding exposed services.
* Exploring security misconfigurations.

### 3. Web Application Security

* SQL Injection.
* Cross-Site Scripting (XSS).
* Authentication vulnerabilities.
* Access control issues.
* Other OWASP Top 10 vulnerabilities.

## 📚 Learning Outcomes

Through this lab, I aim to strengthen my understanding of:

* Network security fundamentals.
* Linux and system administration.
* Vulnerability assessment.
* Web application penetration testing.
* Ethical hacking methodologies.
* Security documentation and reporting.

## ⚖️ Disclaimer

All activities documented in this repository are strictly for educational purposes and are conducted within authorized lab environments.

Intentionally vulnerable applications and machines are used for learning and security testing. No unauthorized systems are targeted.
